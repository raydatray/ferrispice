ECSE 472 Project
Deliverable 1

General description

The objective of this deliverable is to generate the MNA matrices from a given netlist and run linear DC analysis. The input to your program is a netlist that describes the circuit that you intend to simulate, and the outputs are the unknown voltages and currents.

The circuit netlist 

Below is an example of a netlist:

Name of circuit
Vin n1 0 DC 6
R1 n1 n2 100
R2 n2 0 50
.end

The first line is always ignored, since it is used to indicate the name of the circuit you are simulating. The last line must always be ".end" to indicate the end of the netlist. 

The MNA matrices

Your program should read the input netlist, determine which information from the netlist is needed, and then create the MNA matrices. For this deliverable, you are required to implement the stamps for all the circuit elements discussed in class:

  1. Voltage source (must start with V in the netlist)
  2. Current source (must start with I in the netlist)
  3. Resistor (must start with R in the netlist)
  4. Capacitor (must start with C in the netlist)
  5. Inductor (must start with L in the netlist)
  6. Voltage-controlled voltage source (must start with VCVS in the netlist)
  7. Current-controlled voltage source (must start with CCVS in the netlist)
  8. Voltage-controlled current source (must start with VCCS in the netlist)
  9. Current-controlled current source (must start with CCCS in the netlist)

*no need to implement the diode stamp for this deliverable.

Linear DC analysis

Your program should run linear DC analysis. To do so, the user adds the command ".dc" to the netlist anywhere before the ".end" command.
