General description

This objective of this deliverable is to add the diode stamp and to design the nonlinear DC analysis algorithm.

The circuit netlist 

Below is an example netlist:

* diode circuit
Vin n1 0 DC 1
D1 n1 n2
R n2 0 50
.dc
.end

For the diode, Use Is = 1e-14A and Vt = 0.025V.

If you run the circuit above with, the result of your simulation should be: V1 = 1, V2 = 0.2673, and IE = 0.0053.
